# Закреплённые эталонные источники

Сюда положены копии файлов, по которым **машинно** проверяется наш код скриптом
`deploy/verify-sources.ps1`. Копии нужны, чтобы проверка была воспроизводимой:
ссылка на файл в интернете может измениться, а закреплённый коммит — нет.

## `ln8000_charger_extract.h`

| Поле | Значение |
|---|---|
| Источник | <https://github.com/EmanuelCN/kernel_xiaomi_sm8250> |
| Путь в репозитории | `drivers/power/supply/lionsemi/ln8000_charger.h` |
| Коммит (закреплён) | `9e94307b9c1994cba25849099a0582ad3ab00390` |
| Лицензия | GPL-2.0 (Copyright (C) 2021 Lion Semiconductor Inc.) |
| Зачем | определяет адреса регистров LN8000 и битовые маски, которых **не было** в комплекте из `04-android-reference-sources` (там драйвер обращается к регистрам по символическим именам, а сами определения не приложены) |

Это **выдержка**, а не файл целиком: оставлены определения, нужные для сверки
(адреса регистров, битовые маски, числовые константы, коды режимов). Восстановить
полный файл:

```powershell
Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/EmanuelCN/kernel_xiaomi_sm8250/9e94307b9c1994cba25849099a0582ad3ab00390/drivers/power/supply/lionsemi/ln8000_charger.h' -OutFile ln8000_charger.h
```

Используется только для сверки на этапе разработки; в сборку драйвера ничего из
него не попадает, поэтому GPL здесь не влияет на лицензию нашего кода (MIT/Apache-2.0).

## Что именно сверяется

* `enum ln8000_reg_addr` — адреса регистров (0x00 … 0x4D);
* битовые маски `LN8000_MASK_*` и номера битов `LN8000_BIT_*`;
* коды ADC-каналов, режимов и порогов OVP/сторожевого таймера — сверяются
  косвенно, через формулы кодирования и тесты ядра.

Результат последней сверки — `artifacts/verify-sources.txt`.
